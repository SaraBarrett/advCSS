Experimenta nesta página

Uma interface que reage

Usa o botão no topo para alternar o tema. Depois, passa o rato pelo botão de demonstração ou seleciona-o com a tecla Tab. 

.botao-demo {
  transition-property: background-color, transform;
  transition-duration: 750ms;
}

.botao-demo:hover,
.botao-demo:focus-visible {
  background-color: #246f44;
  transform: scale(1.06);
}

Observa a mudança de cor e de escala.
